mini.js is a Transformers.js alternative built entirely from scratch in pure HTML, CSS and JavaScript — its own WebGL2 kernels, tensor engine, tokenizers, safetensors parser and model runtime. Anyone in the world can use it with a single <script> tag.

<script src="https://cdn.jsdelivr.net/gh/poojaverma031990-ui/Omni.js@main/mini.js"></script> 
const llm = await mini.pipeline('text-generation', 'HuggingFaceTB/SmolLM2-135M-Instruct');
const [out] = await llm.chat('Explain gravity simply.');
console.log(out.assistant_message);

The one-line API

Every task is a single await. First call downloads & caches the model — after that it's instant and works offline.

✍️ Generate text

const text = await mini.generate(
  'Once upon a time'
);

🎭 Classify text

const [top] = await mini.classify(
  'I absolutely love this!'
);
// → { label: 'POSITIVE', score: 0.999 }

🧭 Embed text

const vector = await mini.embed(
  'Hello world'
);
// → Float32Array(384), unit length

🕳 Fill the mask

const [best] = await mini.fillMask(
  'Paris is the [MASK] of France.'
);
// → { token: 'capital', score: … }

⚙️ Full control

const gen = await mini.pipeline('text-generation', 'openai-community/gpt2', {
  progress_callback: (p) => console.log(p.status, p.file, p.progress)
});
const [out] = await gen('Once upon a time', {
  max_new_tokens: 100,      // length
  do_sample: true,          // sampling on/off
  temperature: 0.8,         // creativity
  top_k: 50, top_p: 0.95,   // sampling strategies
  repetition_penalty: 1.1,  // discourage loops
  onToken: (id, n) => console.log('token', n)  // streaming
});

How it works — every line hand-written

There is no ONNX Runtime here. No TensorFlow.js. No WebAssembly blobs. No native code. Each layer of the stack was built from nothing, in plain JavaScript.

🧮

Tensor engine

An eager tensor class with two complete backends: blocked, unrolled Float32Array kernels for the CPU and RGBA32F texture kernels for the GPU.

✨

Hand-written GLSL

Matmul (3 layouts), softmax, layernorm, GELU, embedding gathers, slicing and scatter — raw GLSL ES 3.00 fragment shaders over WebGL2 framebuffers.

🔤

Tokenizers from scratch

Byte-level BPE (the GPT-2 byte↔unicode trick, merge ranks, pre-tokenizer regex) and WordPiece (greedy longest-match, ## prefixes) — parsing real tokenizer.json.

📦

safetensors parser

Reads the safetensors binary format directly: JSON header + raw buffers, with F16 / BF16 / F32 decoding via bit manipulation.

🤖

Real transformers

GPT-2 decoder with KV-cache and causal attention, BERT and DistilBERT encoders — attention heads, residuals, layer norms, all as explicit tensor ops.

🎲

Sampling engine

Greedy, temperature, top-k, top-p (nucleus) and repetition penalty — the same toolbox the big libraries have.

🌐

Hub streaming + cache

Streams model files from the Hugging Face Hub with progress callbacks and caches them in the browser, so the second run is instant and offline.

🛡

GPU self-test

On load, every GPU kernel is verified against the CPU reference on known inputs. If anything is off, mini.js silently switches to CPU. Correctness first.
